# MHDA Advocacia

Site institucional de **Minharro de Amorim Advocacia** — escritório em Jundiaí/SP focado em direito cível, trabalhista e previdenciário para pessoa física.

## Stack

Vite + React 18. Sem TypeScript, sem CSS-in-JS — CSS plano com design tokens em `src/styles/colors_and_type.css`.

## Desenvolvimento

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # gera dist/
npm run preview  # serve o build
```

## Deploy

Hospedado na Vercel, conectado ao branch `main` deste repositório. Push para `main` dispara um novo deploy automaticamente.
